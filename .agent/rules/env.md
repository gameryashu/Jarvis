# Python Environment Rules

ALWAYS use this Python interpreter for ALL commands, scripts, and terminal operations:
Y:\jarvis\venv\Scripts\python.exe

ALWAYS activate the virtual environment before running any Python:
Y:\jarvis\venv\Scripts\activate

NEVER use system Python or any other interpreter.

When running main.py, ALWAYS use:
cd Y:\jarvis\jarvis && Y:\jarvis\venv\Scripts\python.exe main.py

The project root is: Y:\jarvis\jarvis
The venv is at: Y:\jarvis\venv
